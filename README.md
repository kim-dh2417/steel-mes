# 성지제강 VICON MES

> 성지제강 **데크 공장 MES(Manufacturing Execution System)** 구축 제안용 프로토타입.
> 현장의 수동 엑셀·이메일 운영을 **웹 기반 생산실행 시스템**으로 전환하는 모습을 데모로 보여준다.

**Live Demo** → [https://kim-dh2417-steel-mes.vercel.app/#/dashboard](https://kim-dh2417-steel-mes.vercel.app/#/dashboard)

---

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트 | 성지제강 VICON MES |
| 성격 | 수주 제안용 프로토타입 (프런트엔드 · 가상 데이터) |
| 대상 공장 | 데크 3공장 (충북 음성) |
| 주력 제품 | 데크 플레이트 (주문 제작 100여 종, 슬리퍼 단위 관리) |
| 공정 흐름 | 신선 → TG → 성형(포밍) → 조립(외주 5라인 주·야) → 출하 |
| 현장 제약 | 전산 시스템 부재(엑셀/이메일), 철분진으로 현장 PC 설치 불가 |

### 구축 범위 (단계적 확산)

| 차수 | 범위 | 상태 |
|---|---|---|
| **1차** | **데크 3공장** | 본 프로토타입 범위 |
| **2차** | 데크 1·2공장 확대 | 추가 확정 (확산 예정) |

> 3공장 MES 성공을 기반으로 1·2공장 확산 및 ERP 연동까지 단계적으로 넓히는 구조.

## 4. 핵심 기능 포인트

현장 Pain Point를 직접 푸는 도메인 특화 기능이 데모의 주인공이다.

| 핵심 기능 | 무엇을 푸는가 | 현장 가치 |
|---|---|---|
| **제작번호 추적 (역추적)** | 원자재 → 신선/TG/성형/조립 → 출하 이력을 한 줄로 추적 | 불량 발생 시 어느 로트·공정에서 비롯됐는지 **역추적** |
| **야적장 슬리퍼 위치 조회** | 100여 종 제품을 현장명 + 슬리퍼 번호로 실시간 조회 | 넓은 야적장에서 **출하 제품 찾는 시간 단축** |
| **공정별 실적 자동 집계** | 신선·TG·포밍·조립 실적을 화면에서 종합·시간대별로 | 엑셀 수기 집계 → **일마감·보고 자동화** |
| **안돈 / 이슈관리** | 설비 정지·품질 이상을 즉시 표시 | **대응 지연 최소화** (현장 PC 불가 환경 보완) |
| **바코드 라벨 (CODE128 / QR)** | 출하 라벨을 1D/2D 바코드로 발행 | 라벨 ↔ 추적관리 **연계의 시작점** |
| **생산 현황판** | 전광판형 실시간 보드 | 분진 환경에서 **공용 디스플레이**로 현황 공유 |

> 표 상단 3개(추적·야적장·실적 집계)가 제안 데모의 1순위 시연 포인트.

## 5. 기술 스택

| 구분 | 사용 |
|---|---|
| 프런트엔드 | **Vanilla JavaScript** (프레임워크 없음) |
| 라우팅 | 커스텀 해시 라우터 (`#/path`) — `NAV_GROUPS` · `ROUTES` |
| 스타일 | 순수 CSS (`styles.css`), Material Symbols 아이콘, Inter 폰트 |
| 시각화 | 자체 구현 — 추이 차트(CSS), 바코드(CODE128)·QR 자체 렌더 |
| 상태 저장 | `localStorage` (실적 목표값) |
| 빌드/배포 | **무빌드 정적 호스팅** (Vercel) |

> 의존성·번들러 없이 `index.html` 하나로 구동되는 경량 구조. 현장 IT 인프라가 갖춰지기 전에도 즉시 시연 가능하도록 설계.
